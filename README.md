# chocobear labs

Eine kleine Sammlung von Apps, beschrieben von mir und geschrieben mit KI.
Diese Seite zeigt, was dabei entstanden ist.

- Statische Seite, keine Cookies, kein Tracking, keine fremden Server.
- Bilder und Videos liegen in `media/`, Anleitung in `media/LIESMICH.md`.
- Veröffentlicht wird automatisch per GitHub Actions, aber nur, wenn alle Medien die Prüfung bestehen.

Schriften: Cormorant Garamond und JetBrains Mono, SIL Open Font License (siehe `assets/fonts/`).
Pixelart in den gezeigten Spielen: [Cute Fantasy von Kenmi](https://kenmi-art.itch.io/cute-fantasy-rpg).
Die Grafiken selbst sind nicht Teil dieses Repos.
